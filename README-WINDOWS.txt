RNG Dashboard - Windows installation

1. Extract this entire ZIP into a permanent folder, e.g. C:\RNGDashboard.
2. Install Python 3.12 for 64-bit Windows (including the Python launcher).
3. Double-click server\windows\Setup.cmd.
4. Enter migration credentials only into the local prompts, not in chat.
5. Open the RNG Dashboard desktop shortcut.

For private remote access, use Tailscale and the HTTPS address it provides.
Read server\windows\README.md for migration, remote access, startup and backups.

Installing this package does not delete or change your existing cloud app.
