# RNG Logo

`RNG Logo.png` is the user's official RNG Logo, extracted unchanged from the image embedded in their supplied financial-report PDF. Use this asset for RNG branding; do not recreate its lettering or symbol.

`Mission signature.png` is the transparent cutout of the user's supplied blue-ink signature. It is used only in the lower-left of the mission-description cell in exported mission-report PDFs. Both download and share use that same signed PDF.

`RNG-App-Icon.png` is an app-icon adaptation of the user's supplied RNG monogram,
prepared with the image-generation editor on a white square background. It is
separate from the original `RNG Logo.png` used in financial reports. Platform
size exports (PNG and ICO) are generated by `next_app/tools/build_icons.py`.
